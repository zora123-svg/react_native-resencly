# Resencly – Technical Notes

A personal reference for everything technical in this project, so I can remember *what* I did and *why*.

Resencly is a **subscription tracker** mobile app (Spotify, Notion, Figma, Adobe, etc.): see the balance, upcoming renewals, and expandable cards for each subscription.

---

## 1. Tech Stack

| Area | Tool / Version | Purpose |
|---|---|---|
| Framework | **Expo SDK** (`expo ^57`) + **React Native 0.86** | Cross-platform (iOS / Android / Web) |
| Language | **TypeScript** (strict mode) | Type safety |
| React | **19.2** with **React Compiler** enabled | Auto-memoization |

## 3. Routing (expo-router)

- **File-based routing**: file in `app/` → screen.
- `app/_layout.tsx` is the root: returns `<Stack screenOptions={{ headerShown: false }} />`.
- **Route groups** `(auth)` and `(tabs)` – parentheses organise files without adding to the URL.
- **Dynamic route** `subscriptions/[id].tsx` – `[id]` is a URL parameter (e.g. `/subscriptions/spotify`).
- `experiments.typedRoutes: true` in `app.json` → type-checked links.
- The app scheme is `reactnativeresencly` (deep linking).
- Entry point: `"main": "expo-router/entry"` in `package.json`.

### Custom tab bar – `app/(tabs)/_layout.tsx`
- Tabs are generated by **mapping over the `tabs` array** in `constants/data.ts` instead of writing each `<Tabs.Screen>` by hand.
- `tabBarShowLabel: false` – icons only.
- Floating pill-style bar: `position: 'absolute'`, `marginHorizontal`, `borderRadius`, positioned at `bottom: Math.max(insets.bottom, inset)` using `useSafeAreaInsets()` so it clears the home indicator.
- `TabIcon` draws an accent-coloured circle behind the icon when `focused` (using `clsx`).
- Sizes come from `components.tabBar` in `constants/theme.tsx`.

## 4. Fonts & Splash Screen

In `app/_layout.tsx`:

1. `useFonts({...})` loads 6 weights of **Plus Jakarta Sans** and returns `[fontsLoaded]`.
2. A `useEffect` calls `SplashScreen.hideAsync()` once `fontsLoaded` is true.
3. `if (!fontsLoaded) return null;` – keeps the app from rendering with fallback fonts.

Font names registered: `sans-light`, `sans-regular`, `sans-medium`, `sans-semibold`, `sans-bold`, `sans-extrabold`.
They are also listed in the `expo-font` plugin in `app.json` (embeds them at build time) and mapped in `global.css` (`--font-sans-*`) so classes like `font-sans-bold` work.

## 5. Styling – NativeWind v5 + Tailwind 4

### Setup chain
1. **`metro.config.js`** – wraps the default Expo config with `withNativewind(config)`.
2. **`postcss.config.mjs`** – enables `@tailwindcss/postcss`.
3. **`global.css`** – imported at the top of the root layout and screens (`import "@/global.css"`).
4. **`nativewind-env.d.ts`** – types for `className` on RN components (generated; don't edit).

### `global.css` contents
- Tailwind imports (`theme`, `preflight`, `utilities`) + `@import "nativewind/theme"`.
- **`@theme { ... }`** – design tokens as CSS variables (Tailwind 4 style):
  - Colors: `background #fff9e3`, `primary/foreground #081126`, `accent #ea7a53`, `card`, `muted`, `border`, `success`, `destructive`, `subscription #8fd1bd`.
  - Fonts: `--font-sans-*`.
  - Spacing scale: `--spacing-1` … `--spacing-30` (4px steps).
- **`@layer components { ... }`** – semantic classes using `@apply`, e.g. `.home-header`, `.sub-card`, `.upcoming-card`, `.auth-input`, `.modal-container`, `.category-chip`. Components then just use `className="sub-card"` – keeps JSX clean.

### Third-party components
`SafeAreaView` from `react-native-safe-area-context` isn't a core RN component, so it is wrapped with NativeWind's **`styled()`** to accept `className`:
```tsx
const SafeAreaView = styled(RNSafeAreaView);
```

### Conditional classes
`clsx('sub-card', expanded ? 'sub-card-expanded' : 'bg-card')`.
Dynamic values that can't be classes (per-subscription `color`) go through the `style` prop.

### Theme duplicated in JS
`constants/theme.tsx` mirrors the CSS tokens (`colors`, `spacing`, `components`) because some APIs (e.g. `tabBarStyle`) need real JS values, not class names. **If I change a colour, change it in both places.**

## 6. TypeScript

- `strict: true`, path alias **`@/*` → project root** (so `@/constants/data` instead of `../../constants/data`).
- **`type.d.ts`** declares *global* interfaces inside `declare global { ... }` + `export {}` so they're available everywhere without importing:
  - `AppTab`, `TabIconProps`
  - `Subscription`, `SubscriptionCardProps` (`extends Omit<Subscription, "id">` + UI props)
  - `UpcomingSubscription`, `UpcomingSubscriptionCardProps`
  - `ListHeadingProps`
- **`img.d.ts`** lets TypeScript accept `import x from "...png"`.
- Icons/images typed as `ImageSourcePropType`.

## 7. Data Layer (currently mock)

`constants/data.ts` holds hard-coded data:
- `tabs` – drives the tab bar.
- `HOME_USER`, `HOME_BALANCE` (amount + next renewal date).
- `UPCOMING_SUBSCRIPTIONS` – id, icon, name, price, currency, `daysLeft`.
- `HOME_SUBSCRIPTIONS` – full details (plan, category, payment method, status, start/renewal date, billing, brand colour).

**Centralised asset imports** – `constants/icons.tsx` and `constants/images.ts` import each asset once and export an object (`icons.spotify`, `images.avatar`). One place to change if a file moves.

## 9. Components

### `ListHeading`
Section title + "View all" button. Props: `title`.

### `UpcomingSubscriptionCard`
Compact card for the horizontal list: icon, price, and `"N days left"` (or `"Last day"` when `daysLeft <= 1`). Uses `numberOfLines={1}` to truncate long names.

### `SubscriptionCard`
Expandable card:
- Collapsed: icon, name, category/plan (falls back to the formatted renewal date), price + billing cycle. Background is the subscription's brand `color`.
- Expanded (`expanded` prop): shows payment method, category, start date, renewal date (and a cancel button styled via `.sub-cancel`).
- Whole card is a `Pressable` that calls `onPress`.

## 10. Home Screen – `app/(tabs)/index.tsx`

Layout: header (avatar, name, add icon) → balance card → **Upcoming** (horizontal `FlatList`) → **All Subscription** (vertical `FlatList`).

Key concepts:
- **Accordion behaviour** – one piece of state: `const [expandedSubscriptionID, setexpandedSubscriptionID] = useState<string | null>(null)`.
  Pressing a card toggles it: `currentID === item.id ? null : item.id`. Only one card is open at a time.
- **`extraData={expandedSubscriptionID}`** on the `FlatList` – FlatList is a PureComponent and wouldn't re-render rows when only outside state changes; `extraData` forces it.
- **Spread props** – `<SubscriptionCard {...item} />` passes every field of the object as a prop.
- `keyExtractor={(item) => item.id}` for stable keys.
- `horizontal` + `showsHorizontalScrollIndicator={false}` for the upcoming carousel.
- `ItemSeparatorComponent` gives 16px gaps between rows.
- `ListEmptyComponent` shows friendly empty-state text.
- `contentContainerClassName="pb-30"` adds bottom padding so the last card isn't hidden by the floating tab bar.
